# 英语写作工作台 · English Writing Workshop

一个**单文件**雅思写作训练应用：把作文拆成逐句引导的「积木拼装」，像 Duolingo 一样拼出每一句，而不是对着空白页发呆。

## ✨ 功能

- **逐句工作台**：中文句意输入 → 词块拼装 → 自动检查（词序 + 标点双重校验，首错只提示位置，再错给分类提示）
- **标点积木**：词内标点（don't / well-known / 1,000）留在词块内；句级标点独立成块，系统标点 ×N 计数、用户标点取之不尽，可拖拽/键盘插入
- **四功能词区**：连词 / 强调结构 / 搭配词组 / 自由配件，73 条内置学术词库（等价替换、易混辨析、强度守恒）
- **观点库侧栏**：论点卡片可拖入中文框复用
- **进度本地保存**：localStorage 持久化，刷新/重开不丢
- **浅色 / 深色**自适应，响应式布局

## 🚀 使用

无需安装任何东西——下载 `index.html`，用浏览器打开即可。

在线版：**https://yasi.bertrammmmm.top/**

> 本仓库为公开版：不包含 API Key，词块生成自动使用内置规则模式，全部功能可用。如需接入 AI（DeepSeek）自动分词，在脚本内 `AI_CONFIG` 处填入你自己的 Key。

## 📝 说明

- 学习进度保存在浏览器本地（键名 `yasi-workshop-v4`），换浏览器/清缓存会重置
